# 第一部分 Agent 的骨架

> "实习生小李刚入职时，主管先教他的不是'怎么做竞品分析'，而是'怎么工作'——接到任务先问清楚要求、查资料用哪些工具、记笔记写在什么地方、做完怎么汇报。这些是最底层的能力，没有它们，再聪明的人也干不成活。"

---

如果你打开一个Agent系统的源码，最先看到的不会是某个炫酷的AI算法，而是一堆"基础设施"——怎么循环执行、怎么调用工具、怎么记笔记、怎么理解指令、怎么输出结果。这些就像人的骨架：没有骨头，肌肉再发达也站不起来。

**第一部分"Agent的骨架"**包含五章，对应Agent系统最基础的五个能力维度。它们之间的关系就像人体的五大系统：

| 章节 | 维度 | 人体类比 | 一句话定位 |
|------|------|---------|-----------|
| 第1章 | 编排循环 | 心跳与神经系统 | 决定Agent"怎么干活"——理解任务、执行工具、观察结果、调整策略的循环节奏 |
| 第2章 | 工具系统 | 双手 | 决定Agent"能干什么"——读写文件、执行代码、搜索网络、调用API |
| 第3章 | 记忆系统 | 大脑皮层 | 决定Agent"记得什么"——对话历史、用户偏好、项目上下文 |
| 第4章 | Prompt构建 | 耳朵与理解力 | 决定Agent"听懂什么"——如何把用户指令、环境信息、工具定义组装成LLM能理解的格式 |
| 第5章 | 输出解析 | 嘴巴与汇报能力 | 决定Agent"说得清什么"——如何把LLM的原始输出翻译成可执行的工具调用或可读的结果 |

## 这五章的阅读顺序

建议按顺序阅读，因为它们是**层层递进**的：

**第1章（编排循环）是起点**。它回答"Agent到底是怎么干活的"——不是一次性输出答案，而是一轮一轮地循环推进。理解了这个"工作节奏"，再看后面的章节，你就知道每个模块在循环的哪个环节发挥作用。

**第2章（工具系统）和第3章（记忆系统）是左右手**。工具系统让Agent能"动手"——查资料、写代码、发邮件；记忆系统让Agent能"记事儿"——别忘了用户上周交代过的偏好。这两章没有严格的先后关系，但建议在读完第1章后再看。

**第4章（Prompt构建）和第5章（输出解析）是输入输出两端**。Prompt构建是"把人类语言翻译成LLM语言"，输出解析是"把LLM语言翻译回机器可执行的动作"。它们是编排循环的"入口"和"出口"，理解它们对理解整个循环至关重要。

## 这部分适合谁重点看

- **如果你打算从零写一个Agent系统**：这五章是必读。它们告诉你"最少需要什么"，以及四个成熟项目分别是怎么做的。
- **如果你在使用现成的Agent框架（如LangChain、AutoGPT）**：重点看第1章和第2章，理解底层循环和工具调用的机制——这能帮你排查"为什么Agent在这里卡住了""为什么工具调用失败了"这类问题。
- **如果你是产品经理或技术负责人**：快速浏览各章的"业务概念"和"设计思想总结"小节，了解每个模块的边界和取舍，避免在方案评审时提出"让记忆系统去做安全防护的事"这类越界需求。

## 一个阅读建议

每章的**12.3节"必要设计：所有Agent都必须有的"**（在对应章中编号不同）是最值得反复看的部分。它从四个项目中提炼了"底线"——如果你要搭一个Agent，这部分是"不能省"的。而**12.4节"四个项目的实现对比"**则展示了"同一个问题可以有多种解法"，帮助你在具体场景下做出选型决策。

好了，骨架搭好了才能长肌肉。让我们从第1章开始——看看实习生小李是怎么"工作"的。
